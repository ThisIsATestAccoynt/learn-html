HTML Tutorial for Beginners

Introduction

HTML (HyperText Markup Language) is the standard markup language for creating Web pages.

HTML Tags

Paragraphs: <p>

The <p> tag defines a paragraph.

Example:

<p>This is a paragraph.</p>

Headings: <h1> - <h6>

The <h1> to <h6> tags are used to define HTML headings.

<h1> defines the most important heading. <h6> defines the least important heading.

Example:

<h1>This is a heading 1</h1>
<h2>This is a heading 2</h2>
<h3>This is a heading 3</h3>

Links: <a>

The <a> tag defines a hyperlink, which is used to link from one page to another.

The href attribute specifies the destination address.

Example:

<a href="https://www.w3schools.com">Visit W3Schools</a>

Images: <img>

The <img> tag is used to embed an image in an HTML page.

The s rc attribute specifies the path to the image, and the alt attribute provides an alternate text for the image.

Example:

<img src="img_girl.jpg" alt="Girl in a jacket" width="500" height="600">

Lists

HTML offers two main types of lists: ordered (<ol>) and unordered (<ul>). List items are defined with the <li> tag.

Example (Unordered List):

<ul>
  <li>Coffee</li>
  <li>Tea</li>
  <li>Milk</li>
</ul>

Example (Ordered List):

<ol>
  <li>First item</li>
  <li>Second item</li>
  <li>Third item</li>
</ol>

Divisions and Spans: <div> and <span>

The <div> tag is a block-level container for other HTML elements, often used for styling or layout purposes. The <span> tag is an inline container used to mark up a part of a text, or a part of a document.

Example:

<div style="background-color:lightblue;">
  <h2>This is a styled division</h2>
  <p>This is some text in a div. <span style="color:red;">This part is in a span.</span></p>
</div>

Text Formatting

HTML has several tags for defining text with a special meaning.

  • <b> - Bold text
  • <strong> - Important text (usually bold)
  • <i> - Italic text
  • <em> - Emphasized text (usually italic)
  • <u> - Underlined text

Example:

<p>This is <b>bold</b> and this is <strong>strong</strong>.</p>
<p>This is <i>italic</i> and this is <em>emphasized</em>.</p>

Advanced HTML

Tables

The <table> tag defines an HTML table. Each table row is defined with a <tr> tag. A table header is defined with a <th> tag. A table cell is defined with a <td> tag.

Example:

<table>
  <tr>
    <th>Firstname</th>
    <th>Lastname</th>
    <th>Age</th>
  </tr>
  <tr>
    <td>Jill</td>
    <td>Smith</td>
    <td>50</td>
  </tr>
  <tr>
    <td>Eve</td>
    <td>Jackson</td>
    <td>94</td>
  </tr>
</table>

Forms

The <form> tag is used to create an HTML form for user input. The <input> tag is the most used form element.

Example:

<form>
  <label for="fname">First name:</label><br>
  <input type="text" id="fname" name="fname"><br>
  <label for="lname">Last name:</label><br>
  <input type="text" id="lname" name="lname"><br><br>
  <input type="submit" value="Submit">
</form>

Semantic HTML

Semantic HTML tags provide meaning to the web page and its content. Examples include <header>, <footer>, <nav>, <section>, and <article>.

Example:

<header>
  <h1>My Website</h1>
</header>

<nav>
  <a href="#">Home</a>
  <a href="#">About</a>
  <a href="#">Contact</a>
</nav>

<section>
  <article>
    <h2>Article Title</h2>
    <p>Article content goes here.</p>
  </article>
</section>

<footer>
  <p>Copyright © 2023</p>
</footer>
